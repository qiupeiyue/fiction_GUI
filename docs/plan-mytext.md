事件轴界面加一个选项卡：文本编辑。
这个功能用来让用户直接通过 UI 写小说，可以一边看自己写的设定、事件发展、人物信息等，一边写小说文本。
有章节边栏。界面主体，左侧一列可参考二维事件图的“章节\事件\人物”一列，对这一列的交互也和二维事件图中一样，但不同的是，双击不是返回事件轴选项卡，而是打开对应事件的编辑框（放在图中红框位置）。在编辑框中用户可以输入文本（小说内容），并且保存成 .md 格式的文档。这个 .md 文档的路径和事件卡一一对应。默认的保存地址是：用户导出 .json 的文件夹下建立一个和 .json 文件名相同的文件夹。例如导出目录为 `C:\Users\you\Documents\fiction_GUI\output`，导出的 JSON 为 `SelfPhobia_2026-10-20.json`，那么 .md 文件就保存在 `C:\Users\you\Documents\fiction_GUI\output\SelfPhobia_2026-10-20` 这个文件夹中（如果没有就新建）。
后面会追加生成小说的功能：按照现在事件轴上事件卡的排序将所有.md文档内容串联起来，并且，自动分段、生成标题第几章第几节...
在文档编辑框内，ctrl+s为保持这个.md文档，enter为正常的换行，esc为退出文档编辑框，其他快捷键都正常使用，比如ctrl+a为全选文本，等等...
