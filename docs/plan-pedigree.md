新增人物分析选项卡：系谱

这个功能不涉及对人物信息卡的任何操作，所有系谱相关的信息都写在“系谱”自己的功能中。
基本架构：
1. 对象（可悬空）
2. 结合线/union line
    线头两端连接父对象1和父对象2：父对象1 - 父对象2 
    自己和自己连结合线，无效，禁用。
3. 世系线/descent line
    线头上端可以是结合线中点或单一父对象：父对象1 ≠ 父对象2：线头上端点位于结合线中点；父对象1 = 父对象2：线头上端点连接单一父对象
    线头下段连接连接子对象
    自己和自己连世系线，无效，禁用。

交互：将人物卡边栏中的人物卡拖进系谱界面，即可添加对象。


基本操作：添加/删除对象；添加/编辑/删除结合线；添加/编辑/删除世系线

## 对齐结论（2026-10-16 用户逐条拍板，实现照这一节）

### 1. 名词与数据（只有一个系谱界面，不再分"系谱词条"）

- **整块画布就一个**，不再有"新建 / 重命名 / 删除系谱"那一层；**同一个画布可以放多个家族**（互不相连的几坨就是几个家族）。
- 数据挂在项目里自己一份：`state.pedigree = { nodes: { [charId]: { row } }, unions: [ {id, a, b} ], descents: [ {id, union, parent, child} ] }`
  - `nodes`：对象＝人物（**同一个人只有一个对象**）；值里只存 `row`（第几代），**x 不存**——横向位置每次自动排（见第 3 节）。
  - `unions`：结合线 `a — b`（`a === b` 无效禁用；同一对不重复；**一个人允许多条结合线＝多段婚姻**，不做性别 / 年龄校验）。
  - `descents`：世系线，上端锚点二选一 —— `union` 非空＝**该结合线中点**（父1≠父2）；否则 `parent` 非空＝**这个对象底边中点**（父1=父2 的单亲）。
- `ensureData()` 给 `state.pedigree` 兜底；`prunePedigree()` 在载入 / 渲染前清掉「人物已经不在人物库里」的对象（**它的结合线一起清掉，挂在那些结合线下面的子对象＝悬空**，照第 6 节）。

### 2. 界面

- 人物分析加第 4 个子页面 `#view-pedigree`（页签：人物分析 / 出场统计 / 势力分析 / 雷达分析 / **系谱**）。
  `switchTab()`（`src/40-modal-control.js` 里那张手写视图名单）、`syncViewTabs()` 的 `REL_GROUP` 都要加 `pedigree`；
  「恢复上次界面」那个白名单已经改成跟着 `#view-<tab>` 走，不用再动。
- 版面 = **画布铺满整页**。人物卡从**全站左侧的人物边栏**（`#char-pane` 里那些 `.char-card`，本来就能拖）拖进画布＝加一个对象
  （落点决定它先待在**第几代**），所以系谱这一页自己**不再另造一份人物列表**；也可以**双击画布空白**＝弹选人面板加对象。
- **画布不缩放**（没有 −/100%/＋，也不抢 Ctrl+滚轮——那是全站的界面缩放）：内容超出就用**原生滚动条**滚动（竖向按代、横向按宽度）。
- 对象美术**和人物关系网同一个样子**（`<g class="rel-node">` 那套）：人物色 62% 玻璃圆 + 白色高光 + 圆体首字（有人设图就圆形裁图），名字写在圈下面 13.5px。
- **人物链回形针**（2026-10-16 加）：在人物链里的对象，圈右上角挂一颗回形针（颜色＝链色）；
  点它＝弹「人物链」成员列表（Esc 关）；点成员＝把这个对象换成那个人（连线跟着走、可撤销；目标已在图上就提示）。
  选中＝圈外加一圈亮边；灰态（有弹窗 / 右键菜单时）= 参考关系网的 `.dim`。
- 左侧仍然一行一代（`F0 / F1 / …` 小标，和拓扑栏同款），**不自动压缩空行**。

### 3. 布局与 auto-tidy（用户 2026-10-16：每次操作都 auto-tidy，但不动行号）

- **代数＝行号**：新对象按落点待在某一行，之后**行号由用户 / 连接操作决定，auto-tidy 绝不改行号**
  （和技能树同规矩：只有「连完之后子级行号 ≤ 父级行号」这种不合法的情况，才把子树推到 `父级行号 + 1`）。
- **auto-tidy 只排横向**：同一代里从左到右铺开；**有结合线的两个人自动相邻**；孩子在它两个父（或单亲）的**中点下方**；
  同一代排不下就整体往右顺延（和技能树 measure / place 一个思路）。**每次操作**（加 / 删对象、加 / 删 / 编辑结合线、加 / 删 / 编辑世系线）之后都跑一次。
- 连线用**排版坐标**（`offsetLeft/offsetTop` 累加到容器）算，别混 `getBoundingClientRect()`（界面缩放时会放大，线会错位）。

### 4. 连线几何

- **结合线**：两个对象中心之间的线；同一高度＝水平直线，有高差＝「横—竖—横」Z 形折线（不走斜线，免得穿过别的圈）。
  两对象中心连线的**中点**画一颗 6px 小圆点＝世系线的**起拖手柄**。
- **世系线**：锚点（结合线中点 / 单亲底边中点）竖直向下 → 折到子对象**圈顶**上方 → 竖直进圈顶（「竖—横—竖」，子对象在正下方时就是一条竖线）；
  同一个锚点下的几条共用同一段横线高度（族谱那种兄弟姐妹横线）。
- 线的命中区加宽（≥ 8px）方便点选；选中的线加粗 + 变色。

### 5. 交互与基本操作

| 做什么 | 怎么操作 |
| --- | --- |
| 加对象 | 人物卡边栏拖进画布（落点＝先待在第几代）／双击画布空白＝选人面板 |
| 移动对象 | 拖对象＝**改它所在的代**（行号跟着走；连着的两端不跟着乱动） |
| 加结合线 | 对象右下角**结合手柄**拖到另一个对象；或右键对象 →「结合…」进入**监听状态**（能连的亮、不能连的灰、Esc 退出） |
| 加世系线 | ① 结合线**中点的小圆点**拖到对象上；② 对象**底边中点的世系手柄**拖到另一个对象（单亲） |
| 替换结合线的一端 | 右键结合线 →「替换「A」…」／「替换「B」…」（监听状态点另一个对象） |
| 替换世系线的端点 | 右键世系线 →「替换下端点」（换子对象）／「替换上端点」（换锚点：点对象＝单亲，点结合线中点＝双亲） |

| 键盘 | Delete＝删除选中；Esc＝退出监听（没监听时＝清空选中）；Ctrl+Z / Ctrl+Y＝撤销 / 恢复 |

  （可撤销，配一条**四语言小气泡**说明，用户 2026-10-16 确认）。

### 6. 删除与清理规则（用户 2026-10-16 拍板：一律只断线，不级联删对象）

- **删对象**：它的结合线 / 世系线都跟着断掉；**连线另一端的对象都保留**（该悬空就悬空）。
- **删结合线**（右键删那条线、两个父都还在）：挂在它下面的世系线一起断掉，**子对象保留＝悬空**（不删子代、也不把子代挂到别处）。
- **删父卡**（2026-10-16 用户澄清，分两级）：结合线两端挂着一个子时 ——
  **删掉其中一个父 → 子卡变成单亲**（世系线改挂到活着的那个父的底边中点）；**两个父都删掉 → 子卡悬空**。
  在系谱里删对象、人物库里删人（载入时 `prunePedigree`）两条路都照这个规则。
- **删世系线**：只断这一条关系，两端对象都保留。
- **人物库里删掉一个人**：系谱里这个对象**自动清理**；**它的结合线一起清掉**；子卡按上面那条（剩一个父＝单亲、没父＝悬空）。
