## 对齐结论（2026-10-15）

### 层级与选择

1. 势力**固定三级**，不再往下加（技能 1.4 可以多级）。
2. 一级、二级可多选；**每条二级分支下只允许一个三级**。
3. 选择互斥：选了 `A1→A2` 就不再单列 `A1`；选了 `A1→A2→A3` 就不再单列上面两级。显示同样不重复父链。
4. 数据：势力卡存 `parentId`（真正的树），显示时拼成 `A1→A2→A3`；`所属：无` ＝ 一级。老存档不动，默认全是一级。

### 改所属（术语按数字定死，免得说反）

5. **升级＝层级数字变小**（二→一、三→二）；**降级＝层级数字变大**（一→二、二→三）。
6. 平级移动：整棵子树跟着走，层级不变。
7. 升级：整棵子树跟着上一层。例：`A1→A2→A3` 里把 `A2` 升成一级，`A3` 就从三级变二级、挂在 `A2` 下面。
8. 降级：整棵子树跟着下一层。例：`A1→A2→A3` 里把 `A1` 降成二级，`A2` 变三级。
   - 降级会把最下面那一代挤出三级时，**超出三级的那一代直接删掉**（不是外挂到上级下面）。例：`和平高中`（一→二，挂到 `临海市` 下）后，`学生会` 变三级，原来的 `学生会主席` 超出三级 → 删掉；人物卡上原来指向它的那条势力也一并清掉。**不弹确认**（和现在删设定条目一样），但整件事可撤销（顶栏撤销 / Ctrl+Z，势力卡和人物卡上那条一起回来）。
   - 降级不能跨级（一级不能直接改到三级，必须一级→二级→三级）；升级可以跨级（三级可以直接改回一级；三级本来没有子级，不牵动子树）。
   - 降级必须指定上级（输入或匹配下拉）。
9. 删除一个有子级的势力：子级一起删，同时清掉人物卡等地方对它们的引用（和现在删势力条目一样）。

### 界面

10. 势力信息卡「概述」下方加「所属」，可以先设 `A1` 再设 `A1→A2`；势力卡右键 + 批量操作加「所属…」。
11. 人物卡「所属势力」分层胶囊：只列一级 → 选中后出现它的二级 → 再出现三级；不同层级用颜色区分。
12. 势力界面加「所属关系」栏（仿地点里的地图栏）：节点可折叠、点击跳到对应势力卡；分栏可折叠、可拖拽调宽；以后可能支持拖拽改层级。
13. 人物分析 → 势力分析：逐级可折叠，子级逐个排在下面一行并缩进。
14. 配色：一级沿用现有配色；二级、三级用同色系不同明度。

### 文本分析

15. 工作区没有分级信息时只识别一级势力，分级交给用户自己设。
16. 工作区已有分级时，文本分析 / 按事件更新等回填要能识别并回填多级。

### 已定（2026-10-15 第二轮问答）
