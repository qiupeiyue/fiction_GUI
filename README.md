# Adaa的小说工坊

一款面向长篇小说作者的本地创作工具：把**人物档案**、**事件轴**、**设定档案**、**文本分析**放在同一个工作区里，边写边整理世界观和情节。

> 多线剧情 · 人物档案 · 设定档案 · 事件轴 · 时间线

> 当前版本：**1.0.0** ｜ 更新时间：**2026-10-09**

## 主要功能

- **多部小说管理**：新建 / 切换 / 重命名 / 删除 / 复制小说，导入导出 JSON 备份。
- **人物档案**：分组、势力、别名、立绘头像、雷达图等；支持拖拽归类、批量操作、自动合并重复人物。
- **人物关系网**：亲属 / 师徒 / 敌对 / 恋爱 / 朋友 / 同事 / 其他等多种关系，支持一键生成与更新。
- **事件轴**：纵轴为叙事顺序、横轴为线路，支持章 / 节分带、事件集、拖动排序、批量合并 / 删除 / 换线。
- **二维事件图**：横轴人物、纵轴事件，直观查看人物登场。
- **时间线**：横轴线路、纵轴时间，按“故事里真实发生的时间”排列。
- **设定档案**：物品 / 名词 / 地点 / 纪年 / 势力等分类，支持自定义字段、图片、关联人物与事件。
- **文本分析**：配置 AI 接口后，导入 PDF / Word / TXT，自动抽取人物、事件、设定并回填工作区。
- **人物分析**：出场统计、势力分析、雷达分析（可多人叠加比较）。
- **撤销 / 恢复**：绝大部分操作可回退，最多保留 10 步；支持快捷键。

## 下载与安装

在右侧（或页面下方）的 **Releases** 里下载最新版安装包：

```
AdaaFictionGUI-Setup-1.0.0.exe
```

当前发布的是 Windows 安装版。双击安装包后，可以自己选择安装目录；安装完成后从桌面快捷方式或开始菜单启动即可。

### Windows 提示「已保护你的电脑」怎么办

这个程序没有购买商业代码签名证书，所以 Windows SmartScreen 或浏览器可能会提示「未知发布者」「Windows 已保护你的电脑」或「不常下载，可能不安全」。这是未签名软件的常见提示，不是程序本身有问题。

按下面操作即可继续安装：

1. 浏览器下载时如果提示风险，点「保留」或「仍然保留」。
2. 双击安装包后如果出现蓝色窗口「Windows 已保护你的电脑」，点「更多信息」。
3. 再点右下角出现的「仍要运行」。
4. 如果 Windows Defender 拦截，打开「Windows 安全中心 → 病毒和威胁防护 → 保护历史记录」，找到这条记录，选择「允许」或「还原」。

安装包来自本仓库 Releases，建议只从这里下载。

软件启动时会自动检查 GitHub Releases 是否有新版本，有新版本会提示并增量更新（只下载变化的部分）。

## 快速上手

1. 顶栏「小说」下拉框新建或切换作品。
2. 左侧建人物、分组、线路。
3. 事件轴上「＋ 新建事件」搭建情节，拖动卡片改时间与线路。
4. 用「文本分析」导入小说原稿，让 AI 帮你抽取人物 / 事件 / 设定。
5. 定期「导出 JSON」备份，或依赖自动保存与自动更新。

详细说明见软件右上角的「？」使用说明。
