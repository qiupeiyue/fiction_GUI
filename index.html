小说与保存

顶栏「小说」下拉框可切换、新建、重命名、删除、复制小说。内容自动保存，建议定期「导出 JSON」备份，用「导入」读回。默认位置在「设置 → 路径」里改。

人物

左侧新建人物和分组；把卡片拖到分组标题上即可归类，右键可换组、编辑、删除，拖动分组标题可排序。人物支持别名、势力、图片和雷达图。

人物关系

在关系网里维护人物之间的关系与类型；同一对人物可以有多种关系并存。新建、修改、删除都能撤销。

合并条目

「自动合并」会找出重复的人物 / 设定并列出，勾选后合并；也可批量勾选手动合并。词条名可选主体名或自定义，其余写法记入别名。

人物分析

提供「出场统计」「势力分析」「雷达分析」三种视图；支持按分组筛选、排序和多选比较，双击定位到对应事件或人物。

线路

明线 / 暗线在事件轴横轴的线路表头管理：新建、改名、改色、排序、删除都在右键菜单，暗线可挂在明线之下。

事件

一个事件可以属于多条线路，填写时间、地点、起因 / 经过 / 结果和登场人物。这里的「时间」指故事里真正发生的时间，不是讲述顺序。

章 / 节

左侧章节栏管理章和节；事件轴与二维图都按章 / 节分带显示。拖动分界线或右键可设置起止范围，双击定位。「自动识别」按文本分析的识别结果建章并把事件归位，「整理」先按章节线现在的位置把下方事件收进对应的章 / 节，再把仍为空的章、节清掉。

事件轴

纵轴是叙事顺序、横轴是线路、左侧是 # 号。拖动卡片改时间和线路，在 # 之间可插入新行；卡片右上角的小三角可折叠详情。

事件集

把相邻的事件归成一个集，折叠成一张卡；双击展开、右键管理（展开 / 全选 / 删除 / 拆分）。

批量

用 Shift / Ctrl 点选进入批量模式，可合并、归章、移动、改线路、删除、复制；只作用于当前显示出来的事件。

二维事件图 / 时间线

二维图：横轴人物、纵轴事件；时间线：横轴线路、纵轴时间。两者都与事件轴保持同步。

设定档案

按类别管理物品 / 名词 / 地点 / 纪年 / 势力等；条目支持字段、关联人物和图片，「纪年」是单列时间轴。

文本分析

新建任务、导入 PDF / Word / TXT、配置 Agent 后抽取人物 / 事件 / 设定，勾选后回填。结果会保留，可单独重跑或删除。

Agent

在「设置 → Agent」里配置接口；可一键禁用。未成功接入时，依赖 AI 的按钮会变灰并提示。

快捷键

Shift / Ctrl 点选、Delete 删除、Ctrl+Z / Ctrl+Y 撤销恢复、Ctrl+A 全选、Ctrl+F 搜索、Ctrl+S 保存、Ctrl+滚轮缩放、Ctrl+0 还原缩放、Esc 退出。

撤销 / 恢复

用右上角按钮或 Ctrl+Z / Ctrl+Y，最多保留 10 步；切换小说会清空记录。

对话框

所有弹窗都是应用内对话框：× / Esc 不保存关闭，Enter 或「保存」按钮保存。
